Our entry for the [Office Joke Open](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232):

> I hit reply-all to ask everyone to stop hitting reply-all, and forty-seven people replied-all to agree.

## How it works

`main.py` holds the joke as a single constant, checks it against the
competition gate (UTF-8 text, 1 to 200 characters, not only whitespace,
a single line), and writes it to `/output/entry.txt` when run:

```sh
python3 main.py
```

No network, no dependencies — Python 3.13 standard library only.
